# Smart NPK Fertilizer Recommendation System

## Overview

The Smart NPK Fertilizer Recommendation System is a web-based decision-support tool designed to assist in analyzing soil nutrient levels and generating fertilizer recommendations.

The application evaluates the three primary macronutrients required for plant growth:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)

Based on user-provided soil data and crop selection, the system identifies nutrient deficiencies, excesses, or optimal levels and provides appropriate recommendations.

---

## Problem Statement

Improper fertilizer application can increase farming costs, reduce soil fertility, and contribute to environmental pollution.

This project aims to provide a simple and transparent rule-based recommendation system that helps promote balanced fertilizer usage and sustainable agricultural practices.

---

## Features

* Crop-specific NPK analysis
* Soil pH input support
* Detection of nutrient deficiencies and excesses
* Rule-based recommendation engine
* User-friendly web interface
* Fertilizer action suggestions

## Workflow

1. Enter farmer and field information.
2. Select crop type.
3. Input soil pH and NPK values.
4. Analyze nutrient status.
5. View fertilizer recommendations.
